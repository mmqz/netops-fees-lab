# ADR 0010 — 地图底图多模式与离线数据分发

日期：2026-10-12（W16-D，v0.6.1）
状态：已接受（需求驱动：v0.6.0 发布后的 issue #1/#2/#9/#11 四条地图缺陷）

## 背景

v0.3.0 引入的地理视图把底图硬编码为 ESRI `Canvas/World_Dark_Gray` 双栅格层——选型标准是「免密钥可用」，刻意规避 CARTO 的匿名水印砖。v0.6.0 发布后用户实测报出四条缺陷：

1. **#1** 画布高度塌陷（CSS 特异性竞败于 MapLibre 注入类，所有平台黑屏）；
2. **#2** Windows 注册表缺 `.mjs` MIME → Worker 以 `text/plain` 加载被拒；
3. **#9** 3D 节点呈巨型光柱（像素换算基准错 2×、高度无上限到 62km、宽度随缩放漂移 11 倍）；
4. **#11** 极简英文底图信息量过低（运维需要中文地名、行政区划、是否沿铁路/公路分布），且无任何切换能力。

用户同时给出明确供给：高德 key（嵌入代码使用）、GitHub Release `mapdata-hlj-2026-10-12`（黑龙江 OSM PBF 全量 + 行政区划/铁路/公路 GeoJSON 提取，© OpenStreetMap contributors），要求「铁路线不能影响主观看或可关掉」「画布能决定显示什么」。

## 决策

### 1. 底图注册表而非硬编码常量

`web/src/components/lab/geoBasemap.ts` 持有唯一注册表 `BASEMAPS`：高德街道（webrd style=8）、高德卫星（webst style=6 + style=8 路网标注透明叠加）、ESRI 极简（v0.6.0 原底图保留为「极简」档）、离线极简（`tiles: null`——画布底色即最终底色）。每项声明 `attribution`（合规随源切换）与 `isGCJ`（坐标系事实）。底图切换 = `map.setStyle` 整样式重建 + 一次性 styledata 回填（数据/塔/可见性），相机保持。

**否决的替代**：运行时 `setPaintProperty`/`source` 增删切换——MapLibre 对「换栅格源」没有一等 API，逐层搬运等于手工重建样式的一半且状态面更大；整样式重建路径与 v0.6.0 已有的「瓦片失败重建无栅格样式」是同一条代码路径（rebuildStyle），复用而非新造。

### 2. 坐标系契约：存储恒 WGS84，渲染按底图投影

业务数据（设备/链路/塔/fitBounds 包围盒）存储与计算恒 WGS84；仅在高德（GCJ-02 火星坐标）底图渲染前经 `projLngLat` 逐点转换（标准偏移算法，国界外恒等）。单一投影入口杜绝「设备漂移到河里」。

**离线叠加图层仅在 WGS84 底图（极简/离线）下可用**：WGS84 数据叠加在 GCJ 底图上偏移 ~500m 且高德栅格已含同类信息——面板禁用并提示，而非静默叠加。这是「坐标系不匹配宁可少显示不可错显示」的诚实取舍。

### 3. 离线数据随二进制内嵌分发

Release 的四个 GeoJSON 提取（RDP 简化 + 属性精简 + 5 位小数，共 1.71MB `.geojson.gz`）放入 `web/public/mapdata/` → vite 构进 `internal/webui/dist/mapdata/` → `go:embed all:dist` 进二进制。服务端（`webui.go`）对 `*.geojson.gz` 声明 `Content-Type: application/geo+json` + `Content-Encoding: gzip`——浏览器透明解压，MapLibre `fetch` 到纯 JSON。36MB 的 PBF 源文件不入库（Release 即存档，需要时重新提取）。

**收益**：内网部署单二进制即得带中文行政区划/铁路/公路的可用地图（叠加图层 + 离线底图），无外网依赖。**代价**：二进制 +1.71MB（34MB 中占比可忽略）。

**否决的替代**：PBF→瓦片（tilemaker 生成 mbtiles/pmtiles 自建矢量底图）——需要引入瓦片生产链、自建样式与字形全套，体积与维护成本远超本期范围；本地 GeoJSON 叠加已满足「区划边界 + 铁路 + 公路 + 地名」的运维参照需求，记为后续演进方向。

### 4. 图层面板与默认值

右上角折叠面板三分区：底图（radio×4）/ 叠加图层（行政区划、铁路、公路）/ 业务图层（设备、链路）。偏好 localStorage 持久化。默认值裁决：**行政区划开**（运维第一问「设备属于哪个区县」）、**铁路关、公路关**（用户明示铁路不得干扰主观看——默认关 + 一键开优于「开着但样式极淡」：淡仍有视觉噪音且用户无感知控制权）。叠加/业务开关即时 `setLayoutProperty`（不重建样式）。

### 5. 3D 定位：倾斜相机示意，不做地形

issue #9 给出两个方向（真地形 DEM / 文档化倾斜示意），取文档化：UI tooltip 与 README 明示「柱高示意连接数，非地形高程」。柱体参数修正：metersPerPixel 按 MapLibre 512px 世界坐标（`78271.517·cos(lat)/2^z`，v0.6.0 的 256px 基准系统性放大 2×）；footprint 7px 为直径语义；高度（米）数据驱动 `heightM` 钳制 [60, 4000]，zoom 期间 rAF 节流同帧重建（与 footprint 一致，不用 zoom 表达式——嵌套 min/max 的样式校验风险且与几何重建双轨失同步）。

**取舍**：物理上限优先于「省级恒定可见」——省级缩放下柱体屏高 ~5px（设备可见性由 HTML 地标承担），城市级恢复 40-58px 与连接数差异。这是对「62km 光柱遮挡底图」缺陷的反向校准。

### 6. 瓦片失败降级看门狗

v0.6.0 的「连续 3 次瓦片错误 → 离线」在 W16 实测中暴露两类问题：

- **假阳性**：相机飞行（初始 fitBounds）取消在途瓦片，MapLibre 对取消的请求同样发 `AJAXError: Failed to fetch (0)`——与真实断网**无法从消息区分**；恰好 3 张初始瓦片被取消即触发误降级。
- **假阴性**：错误波若停在宽限期内不再重发（实测：初始 6 错误后 MapLibre 停止重试），单次判定永远等不到第三次错误。

修正为**周期看门狗**（1s）：连续失败 ≥3 且 距「最近一次底图成功数据 or 样式重建」≥ 4s → 降级。相机飞行的取消错误会被随后 ~1s 内的新瓦片成功清零；真实断网则无成功事件、窗口期满即降级（覆盖停滞态）。降级为渲染态而非偏好：用户切换/点回原底图即重置降级重试；面板 radio 反映 effective 状态（降级时离线档选中）——否则点已选中项是 no-op，用户卡死在降级态（W16 回归实测发现并修复）。

### 7. MIME 钉死在服务端

`webui.go` 显式 MIME 表（.mjs/.js/.geojson/.wasm/.webp/.avif）先于 `FileServerFS` 设置——Windows 注册表缺失不再影响 Worker 加载；附带把目录路径（/assets/、/mapdata/）从 FileServerFS 目录列表改为 SPA 回落（关闭目录枚举）。

## 后果

- 正面：四条 issue 的验收标准全数满足（浏览器级回归 15 项断言全绿）；内网单二进制可用性实质提升；底图/叠加/业务三个维度都有用户控制权；高德底图中文运维体验对齐目标用户。
- 负面/已知限制：离线图层中文名依赖 OpenFreeMap 字形 CDN（完全离线时标注静默消失，线面几何不受影响——本地字形库记为后续工作）；高德瓦片可用性无 SLA（生产使用需评估，与 OpenFreeMap 同等风险面）；1.71MB 数据体积随二进制分发（相对 34MB 可忽略）。
- 开发沙箱已知问题（不影响用户）：Playwright 无头浏览器对**页面世界**的 autonavi 请求封禁（curl/worker/隔离世界均可达，ESRI 同路径正常）——瓦片在线加载在本沙箱无法端到端复现，回归以「URL/样式/坐标投影正确性 + ESRI 全链路 200 + 降级路径」为证据基线。
