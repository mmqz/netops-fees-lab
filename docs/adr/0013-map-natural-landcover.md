# ADR-0013: 自然地表覆盖与离线简洁底图

- 状态：已采纳（v0.6.4，issue #15）
- 日期：2026-10-12
- 关联：ADR-0010（底图多模式）、ADR-0012（相机独立与高程可见化）、issue #15

## 背景

用户在 v0.6.3 验收后反馈：2D/3D 地图「全是陆地、没有水、没有森林」。根因
不在渲染层——离线数据提取时（v0.6.1）只导出了道路/铁路/行政边界，OSM 的
`natural`/`landuse`/`waterway` 面要素与 `place` 地名节点整体缺席。用户同时
给出明确期望：2D 要"干净的、只有河流交通、树林是绿的、类似高德标准地图但
不要那么大的商铺标注"；3D 要"能看见实际高度的比较自然的、真实地理数据要有
河流"。另被问及"高德地图数据是否确定能拿到"。

## 决策

### D1 — 自然要素为离线矢量资产，而非在线瓦片
`scripts/gen_natural.py` 从既有 PBF（Release mapdata-hlj-2026-10-12）提取
29,449 条要素 + 17,615 地名，分级 RDP 简化（森林 ~90m / 河流 ~30m / 溪流
~24m——刻意保住大兴安岭树枝状水系形态）+ 5 位小数量化，gzip 8.7 MB 内嵌
（go:embed）。理由：①内网可用（本项目核心部署形态）；②完全可控的"干净"
观感（自有矢量天然无 POI，高德栅格无法去 POI）；③与既有 DEM/等高线同构
（同一 mapdata 目录、同一 webui gzip 分发管线）。**拒绝**的替代方案：运行
时对 40k 要素逐点 wgs84ToGcj02（CPU 一次 ~秒级、代码路径复杂）——改为
**预投影 GCJ-02 变体**（与等高线 W17 同策略），双文件分发。

### D2 — offline 底图升级为浅色"简洁底图"并设为默认
`BasemapDef` 增加 `theme: light | dark`；offline → light（暖白底 + Amap 系
自然配色 + 白路灰壳 + 棕等高线），amap → light，amap-satellite / esri →
dark（原配色）。叠加图层配色、hillshade、等高线、地名全部按主题取色。
默认底图从 amap 改为 offline：用户明确要"干净"，且高德栅格的 POI 无法
去除；高德街道/卫星保留为可选在线模式（实测可达：REST key 有效、瓦片
200）。偏好存储键升级 `netops-lab.geo.layers.v2`——旧 v1 偏好不迁移，
保证升级即见新默认（否则老用户仍停在 amap 看不到修复）。

### D3 — 叠加开关分两类：坐标变体决定可用域
- **交通/区划**（admin/railway/road）：仅 WGS84 底图可用（既有契约不变：
  GCJ 底图上叠加会偏移且其栅格已含同类信息）。
- **自然要素/地名**（forest/water/green/places）：双坐标变体 → **任意
  底图可用**（与等高线一致）。图层面板分「自然要素」「交通与区划」两组，
  铁路默认关（不干扰主观看）、公路默认开（用户要交通）、自然要素默认开。

### D4 — 3D 不加"自然专用渲染路径"
自然面/水系线直接叠加在既有 DEM terrain 上（MapLibre 图层天然随地形
拉伸）——森林给山脉上色、河流随山谷走势。不为 3D 复制图层或做特殊投影，
保持"同一套数据、两种视图"的架构（区别仅在 setTerrain/相机，见 ADR-0012）。

### D5 — 数据纪律
- 资产同步追加到 Release `mapdata-hlj-2026-10-12`（来源可追溯，PBF 为
  原始事实源，简化派生可由脚本重跑）；
- 署名 © OpenStreetMap contributors（与既有叠加一致）；
- 脚本可重跑（`python3 scripts/gen_natural.py`），osmconf 关键指令
  `closed_ways_are_polygons` 有内联注释（缺失时森林面静默掉进 lines 层
  ——本轮实际踩过并写进 issue-15 文档）。

## 后果

- 二进制 +8.7 MB（27.7 → ~36 MB）：离线完整性优先于体积（与 DEM/等高线
  同一权衡）。
- 极近观（z≥13）森林轮廓为 ~90m 容差的简化几何：省级/市级运维视野无损，
  街区级精度需求出现时再评估矢量瓦片化（tippecanoe + pmtiles）。
- 地名四级 minzoom（市 4.2/县 6.5/镇 8.8/村 11）：防低 zoom 标注洪水，
  与高德标准地图的层级观感对齐。
