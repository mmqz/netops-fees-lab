# ADR-0012：地图视图独立相机与高程可见化（用户反馈轮）

- 状态：Accepted（v0.6.3，2026-10-12）
- 关联 issue：#12（2D/3D 相机锁联 + 默认比例）、#13（地理高程支撑不可见）、#14（发布断档）

## 背景

v0.6.2 交付后用户现场反馈三条缺陷。逐条根因分析后发现三个事实：

1. **相机锁联是结构性的**：GeoCanvas 单实例同时承载 geo2d/geo3d，center/zoom
   全程共享，仅以 ±1.3 zoom 补偿近似对齐视野。用户在 2D 平移后切 3D，
   3D 继承 2D 相机——「两个图锁在一起」。这不是 bug 而是当时的设计取舍
   （单 WebGL 上下文、零重建成本），但与运维场景「2D 看布局、3D 看地形」
   的双视角工作流冲突。
2. **高程支撑已绑定但不可见**：`setTerrain({source:'dem', exaggeration:1.2})`
   在 v0.6.2 确已生效（回归断言过 `getTerrain().source`），但整省远观
   （z≈5.5、视域 ~400km）下 1500m 起伏 ×1.2 占屏 <1%，视觉全平；2D 侧
   只有 hillshade，等高线与海拔读数不存在。**「已设置」≠「已可见」**——
   回归只断言了前者。
3. **修复从未送达**：远端 tag 已至 v0.6.0、main 已至 v0.6.2，但 GitHub
   Releases 停在 v0.3.0。用户在 v0.3.0 上的全部抱怨（无聚簇、无 DEM、
   比例粗）字面成立。**代码修复不等于用户可感知的修复**。

## 决策

### D1 — 每视图独立相机快照（#12）

- 组件内 `viewCamerasRef` 维护 `{geo2d, geo3d}` 两份相机快照；视图切换
  effect 在**离开旧视图时存**（center/zoom/bearing/pitch）、**进入新视图
  时恢复**；首次进入（无快照）按该视图 fitBounds；数据未到仅纠正
  pitch/bearing。
- 经拓扑图中转 = GeoCanvas 卸载重挂，快照自然丢弃 → 重新适配。不做跨
  挂载的持久相机（复杂度不值：用户语义是「重新进来看全局」）。
- 保留单实例（不双 maplibre 实例）：WebGL 上下文与瓦片缓存成本不变，
  仅状态分离。±1.3 zoom 补偿 hack 移除（独立相机后无意义）。

### D2 — 高程三重呈现，全部「可见」导向（#13）

- **自适应地形夸张**：`terrainExaggerationFor(zoom)` 分档（<6.5→4，
  6.5–8→2.5，≥8→1.3），zoomend 重挂。取舍：远观夸张不是「真实比例」，
  但用户诉求是「看得到起伏」；近观回到 1.3 接近真实。诚实起见，
  LAB_GEO_OV_TERRAIN_TITLE 说明数据源而 UI 不谎称比例。
- **等高线**：离线生成（`scripts/gen_contours.py`，marching squares +
  RDP），不引入运行时计算；**GCJ-02 预投影双变体**——生成期逐顶点
  wgs84ToGcj02，让等高线在高德（默认）底图上不偏移、任意底图可用。
  代价 +1.4MB 内嵌体积，换取「默认底图下高程可见」（这是本次修复的
  核心验收点）。等高线与行政区划/铁路/公路叠加的可用性规则**不同**
  （后者仍限 WGS84 底图，数据量大且 GCJ 底图自带同类信息）。
- **光标海拔读数**：客户端解码 terrarium 瓦片采样（不依赖
  queryTerrainElevation——2D 无 terrain 时它不可用）。GCJ 底图下单步
  近似逆偏移（g−(T(g)−g)，误差 <2m，对海拔读数足够）。

### D3 — 回归断言升级为「视觉有效」（#13 的教训）

- 新断言：远观/近观夸张分档（C3/C4）、等高线源加载 + 默认可见（A3/A4）、
  相机恢复含自定义 bearing（G2）、海拔数值与覆盖外降级（H1/H2）。
- 「绑定即通过」的断言模式被明确废弃；涉及视觉的修复必须有 DOM/状态
  级断言或 VLM 截图复核留档（tmp/，不进交付物）。

### D4 — 发布纪律（#14）

- 里程碑收口 = tag + GitHub Release（linux 二进制 + source tar.gz）+
  `/api/health` 实报版本核对，三步缺一不算交付。
- 截屏仅存 repo `tmp/` 作回归证据，**永不**进入 download/ 与 release 资产
  （用户明确要求）。

## 后果

- 正面：三条反馈根因闭环；等高线全底图可用；回归 21/21 覆盖视觉有效性。
- 负面/接受：dist 增至 14MB（等高线双变体 +2.8MB）；远观地形夸张 4×
  非真实比例（近观回真，标题不谎称）；拓扑图中转会丢地图相机（设计
  如此，语义清晰）。
- 后续可选：等高线生成参数化（更细间距需更高分辨率 DEM）；跨挂载相机
  持久化（若用户提出）。
