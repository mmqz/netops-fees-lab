# ADR-0015: 真实公开数据的嵌入边界（v0.8.0）

日期：2026-10-13　状态：已采纳（v0.8.0 W26-W28）

## 背景

v0.7.0 收口后（14 issue 全关、数据模型 v1.0 里程碑完成），演示数据集仍是
合成形态（geodevices 坐标为「演示近似值」）。用户指令明确下一阶段方向：
「数据用互联网公开数据填充，完全找不到的用模拟数据」。真实数据的候选源
与可达性实测：OSM PBF（已有 HLJ extract）、OpenCelliD 快照（HuggingFace
镜像可达，119MB）、高德 Web 服务 API（key 可用，POI 可查）、RIPE Atlas
（可达但 HLJ 无探针）。

## 决策

1. **内嵌真实数据仅采用可合规再分发的公开许可源**：OSM（ODbL 1.0）与
   OpenCelliD（CC BY-SA 4.0）。派生资产（工作簿、地图图层）随仓库与
   二进制分发，署名在 UI attribution + `docs/data-sources.md` 文档级双呈现；
   OpenCelliD 派生物若仓库转公开须按 share-alike 提供——已在文档声明。
2. **高德 POI 不内嵌**：Web 服务 API 条款限制缓存/再分发。高德保持既有
   在线底图角色（四模式之二）。这是「内嵌资产必须可合规再分发」原则的
   直接推论，不因 key 可用而松动。
3. **走廊口径**：光缆逐米路由非公开数据。以 OSM 公路/铁路**按线路名**
   选取真实几何代表「干线走廊」（哈大齐/哈牡/哈佳/佳牡/齐加/加漠/哈伊），
   光缆长度=走廊锚点链测地里程。走廊并集长度含平行车道重复计数，只作
   图层参考不作台账值——两个数字分开报告，不混用。
4. **模拟数据白名单**：机房/纤芯占用/波道占用/电路编号/IP/客户/业务/
   专线/性能数值等台账细节。锚定真实位置（局站/坐标），数值确定性生成，
   `manifest.json` 与 data-sources.md 双处披露。真实列与模拟列不混写在
   同一字段（长度=真实测地值；芯数=模拟——字段级分列）。
5. **基站身份用真实 CGI**：OpenCelliD 主小区的 MCC-MNC-LAC-CID 派生
   站编码——可回溯到源数据行，聚类口径（~110m 网格）写入文档。

## 后果

- 演示叙事升级：哈尔滨→漠河沿线是真实地理（G10/滨洲线/嫩林线/京漠线），
  基站是真实位置（1,198 站含 844 个 NR 5G 小区），影响分析从真实干线
  下钻到虚构客户——「真实骨架 + 披露的模拟血肉」。
- 地理视图新增两个离线图层（光缆干线/无线基站，双坐标变体任意底图可用），
  图层面板新增「真实网络数据」分组。
- 合规成本：mapdata attribution 增 OpenCelliD 条目；data-sources.md 成为
  数据资产的署名中枢（含 MNC 映射、众源覆盖偏差的如实说明）。
- 测试负担：e2e_realdata_test.go（31 工作簿导入链 + 跨层影响链）与
  webui 新图层资产测试进入门禁，数据集漂移即红。

## 与既有 ADR 的关系

- ADR-0010/0012/0013（底图/相机/地表覆盖）：本 ADR 延续「离线优先、
  attribution 呈现」的地图设计线。
- 仓库合规声明（README 顶部）：合成数据例外清单新增「公开许可真实数据」
  一类，红线「no real network data」不受影响——公开数据不是运营商标注
  的网络数据。
