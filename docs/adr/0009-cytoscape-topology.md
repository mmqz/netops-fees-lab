# ADR 0009 — Cytoscape 拓扑画布（依赖选择、单 chunk 嵌入、确定性渲染）

- 状态：已采纳（2026-10-09，Phase 2 / P2-T6）
- 背景：`/lab/:id` 页面需要一个交互式拓扑图：节点=设备（up/down 分色）、边=链路（实线/虚线）、点击联动右侧表格、布局可切换。交付形态是 **Go 单二进制 + go:embed 离线可用**（ADR-0005），不允许任何运行时 CDN/网络依赖。
- 关联：[ADR-0005](0005-frontend-embed.md)（前端嵌入），[docs/simulation.md](../simulation.md) §6（确定性保证）。

## 决策

1. **依赖：`cytoscape@3.32.0` 精确版本、零插件**。
   - 候选与否决：D3.js（更底层，图布局/命中测试/缩放全要手写）；react-flow（节点是 React 组件、交互好，但布局面向流程图且体积相当）；ECharts graph（功能全但拖来整个 ECharts 运行时）；手写 SVG/Canvas（27 节点可行，但缩放/拖拽/命中/文字环绕的工作量与缺陷面不成比例）。Cytoscape 专注图论可视化，自带 `cose`/`grid`/`circle` 布局与 canvas 渲染，类型声明随包发布（无需 `@types`）。
   - **精确 pin `3.32.0`**（`package.json` 无 `^`）：图库的 API/行为面广，升级必须显式审查；零插件（不用 fcose/cola 等布局扩展）——内置 `cose` 对 5–50 节点足够，每个插件都是新的供应链与行为面。
   - 这是本仓库**唯一**的前端图表依赖（P1 手写 CSS 设计系统的原则不变，见 ADR-0001 精神）。
2. **单 chunk 嵌入、不代码分割**。构建产物 js 717.63 kB（gzip 226.73 kB，其中 cytoscape 约 400–500 kB）；>500 kB 的 vite 警告**信息级、已知、接受**。理由：
   - 二进制以 `go:embed` 整体打包（ADR-0005），动态 import 产出的多 chunk 无法带来任何离线收益——反正全在二进制里；
   - 分割反而引入请求瀑布（本地单文件服务下无意义）与构建复杂度；
   - gzip 后 227 kB 对本地单用户工具是瞬时加载；
   - 若未来要瘦身，正确路径是把 cytoscape 从主包剥离成**懒加载路由 chunk**（/lab 专属），而非按库拆分——当前规模不值得。
3. **确定性渲染：布局切换，不持久化坐标**。
   - 节点/边样式是状态函数：up → `#2F5FE0`、down → `#D64545`（节点），实线 `#5C6B85` / 虚线 `#B9C2D4`（边）；**没有"用户拖过的坐标"概念**——数据更新做**增量同步**（保留既有节点位置、仅新增节点参与重排），布局切换（力导/网格/环形）是显式按钮触发的重算。
   - 为什么不持久化坐标：坐标系是**视图态**而工作区状态哈希是**模型态**（§6）——两者耦合会让"同一状态"呈现不同图片，破坏演示可重复性；且拖拽自由度与确定性校验（哪些节点该高亮）无收益。用户想要的"记住布局"由增量同步隐式提供。
   - 选择联动是程序化的：`autounselectify` 关闭手势改选态，点击回调 `onSelect` 驱动右侧表格；表格行点击反向 `cy.select()`——双向联动不走任何持久层。
4. **5–50 节点定位，不做全网图（红线）**。
   - 画布服务**单工作区**（一次物化的虚拟拓扑）；cose 布局、字体、命中区都按这个量级调校。
   - 为什么不做"全库资源关系大图"：P1 的资源关系网络是**导入态**（数百节点 + 全库边），渲染它既慢又不可读，且模糊了"仿真工作台（模型态）"与"资源浏览（导入态）"的边界——后者已有 1/2 跳子图查询（`/resources` 抽屉）。演示数据的 27 节点正是目标量级的下沿锚点。

## 实现要点（`web/src/components/lab/TopologyCanvas.tsx`）

- 实例在 `useEffect` 中创建、卸载 `cy.destroy()`（StrictMode 双挂载安全）；
- `ResizeObserver` + window resize → `cy.resize()`（画布区绝对填充 60% 左栏）；
- 数据更新走元素 diff（新增 add / 删除 remove / 属性 patch），不整图重建——用户当前视角在 ops/undo/恢复后保持稳定；
- 多行标签：节点 label = `code\nname`，边 label = 链路标签（电路编号）。

## 后果与验证

- 正面：`cd web && npm run build` tsc strict 零错误；构建后 dist 恢复 `.gitkeep`（postbuild，ADR-0005 机制不变）；`/lab` 全流程（建台 → 画布 → 启停/配置/ops → checks → diff → undo → checkpoint）已由 P2-T6 实现并经 API 契约测试支撑。
- 权衡：bundle +502 kB（215.2 → 717.63 kB，gzip 226.73 kB）——为拓扑可视化支付的一次性成本，接受并记录于此。
- 未验证（诚实）：真实浏览器中的**视觉效果**（布局观感、虚线、缩放手感）未在本环境人工确认——结构断言与构建通过，浏览器冒烟留给终审（P2-T8 / agent-browser）。
