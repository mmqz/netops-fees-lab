# 2D/3D 地图缺地表覆盖：全是陆地、没有水、没有森林（用户反馈）

## 现象（用户反馈，2026-10-12，v0.6.3 验收后）
- 2D/3D 地图（任意底图）上黑龙江呈现为一片"空白陆地"——**没有森林、
  没有湖泊水面、没有河流**；与真实地貌（大兴安岭连片林区 + 密集树枝状
  河网）严重不符。
- 用户期望（原话）：「我希望 2d 是比较干净的只有河流交通这些的，树林是
  绿的，类似高德的标准地图，但是不需要高德那麽大的商铺标注」「3d 是能
  看见实际高度的比较自然的，真实的地理数据要有河流」。

## 根因
离线地图数据提取时（v0.6.1，Release mapdata-hlj）只挑了道路、铁路、
行政边界三类线划——PBF 里的 `natural`（wood/water/grassland/wetland…）
与 `landuse`（forest/farmland/meadow…）两大类**整体未被提取**：
OSM PBF 原始计数：natural=wood 12,931、natural=water 6,625、
waterway=river 3,768、waterway=stream 2,615、landuse=forest 3,860、
natural=grassland 1,180、natural=wetland 371、farmland ~7,000。
此外默认底图为高德栅格（在线 + 商铺 POI 密集），内网场景下还会瓦片
失败降级为"纯色底 + 线划"——地表覆盖缺失被进一步放大。

## 修复（v0.6.4）
- **数据**：`scripts/gen_natural.py` 从既有 PBF 重提全量自然要素——
  29,449 条（森林 12,955 / 水域面 4,961 / 河流 3,591 / 溪流 2,309 /
  渠 1,113 / 草地灌木农田湿地 4,557）+ 17,615 个地名点；分级 RDP 简化 +
  坐标量化，gzip 共 8.7 MB，随二进制内嵌（双坐标变体：WGS84 + GCJ-02
  预投影，高德底图不偏移）。资产同步追加到 Release mapdata-hlj-2026-10-12。
- **2D 干净底图**：离线底图升级为浅色「简洁底图」并设为默认——森林绿、
  水面蓝、河流线、地名 + 交通区划，无任何商铺/POI 标注（自有矢量天然
  无 POI）；图层面板新增「自然要素」分组（地名/森林/水系/草地农田，
  默认全开），公路默认改为开；偏好键升级 v2（旧 amap 默认不沿用）。
- **3D 自然呈现**：自然要素贴在既有离线 DEM 地形上——森林给山脉上色、
  河流随山谷走势、湖面嵌在正确海拔。
- **高德可达性实测**（用户问「确定高德的地图数据能正常拿到？」）：
  REST district API key 有效（status=1 "OK"）、JS loader HTTP 200、
  栅格/卫星瓦片 200——数据可达；但其标准栅格自带商铺 POI 无法去除，
  故高德降为可选在线底图（保留四模式切换）。

## 验收
- 浏览器回归 35/35 PASS（N1–N11：natural 源 ≥2 万条、森林/水面/河流/
  草地默认可见、地名图层、公路默认开、默认无栅格源、资产 200×4、
  GCJ 变体切换/恢复；E0/E4/E5 面板与开关）。
- 已知限制：自然要素为 RDP 简化后的派生数据（森林 ~90m 容差），极近观
  （z≥13）下轮廓精度低于原始 OSM；村落地名 z≥11 才显示（防低 zoom 标注
  洪水）；高德底图在线时其自有 POI 仍会显示（栅格不可编辑）。
