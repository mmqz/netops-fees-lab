# 地理高程支撑不可见：3D 无视觉起伏、无等高线、无海拔读数（用户反馈）

## 环境
- 来源：用户现场反馈（2026-10-12）：「2D/3D 地图仍然没有地理高度地图来支撑」
- 版本：v0.6.2 @ 769ad37（用户实际运行 v0.3.0——该版本完全没有 DEM，见 issue-14）

## 现象与根因（两层）
1. **用户侧（v0.3.0）**：无任何 DEM/地形/等高线——抱怨字面成立。
2. **v0.6.2 HEAD 侧**：`setTerrain({source:'dem', exaggeration:1.2})` 已
   绑定（回归 C1 断言过），但整省远观（z≈5.5、视域 ~400km）1500m 起伏
   ×1.2 占屏 <1%——**视觉全平**（VLM 复核 tmp/w17-3d-terrain.png 确认
   「平面化、无 DEM 起伏」）；2D 仅有 hillshade，等高线与海拔读数不存在。
   **教训：回归断言了「已绑定」，未断言「已可见」。**

## 修复（v0.6.3）——高程三重呈现，可见导向
- **自适应地形夸张**：`terrainExaggerationFor(zoom)`（<6.5→4，6.5–8→2.5，
  ≥8→1.3），zoomend 重挂；远观起伏可见、近观回真实比例。
- **等高线图层**：`scripts/gen_contours.py` 从 97 块 z8 terrarium 瓦片
  marching squares 生成 200m 首曲线/500m 计曲线 + 高程标注（18,604 条，
  gzip 1.4MB）；**GCJ-02 预投影双变体**——高德（默认）底图上不偏移，
  任意底图可用（不随 GCJ 禁用，规则不同于行政/铁路/公路叠加）。图层面板
  独立开关（默认开）。
- **光标海拔读数**：`geoElevation.ts` 客户端解码 terrarium 瓦片双线性采样，
  左下角实时「海拔 N m」chip；GCJ 底图下逆偏移采样；覆盖外「—」降级。
- 回归：C3/C4（夸张分档）、A3/A4（等高线可见/加载）、E3（开关）、
  H1/H2（大兴安岭 772m / 覆盖外 —）；VLM 截图复核 3D 起伏与等高线可见性。
- 设计决策：[ADR-0012](../adr/0012-map-camera-independence-and-elevation.md) D2/D3。
