### `telecom-base-station.xlsx` 单独披露（W2-D）

- **列布局为真实**：`基站类型/无线基站名称/基站编码/电联共享/归属A IP/环/链/归属A名称/归属A端口/网关IP/基站IP/描述/工单号/备注` 逐字来自项目所有者会话粘贴的运营商真实表头（14 列，**无地市列**）；
- **行 2 为半真实行**：`无线基站名称=动力机房2`、`基站编码=（空）`、`归属A IP=4.28.2.3`、`归属A名称=枢纽楼A4`、`归属A端口=gei_1/11`、`网关IP=12.17.10.126`、`基站IP=172.7.10.125/30`（带掩码）、`工单号=202366` 均逐字来自会话粘贴；**未粘贴的 6 个单元格**（基站类型/电联共享/环/链/描述/备注）填入代表性合成值（宏基站/是/环1/链1/BBU接入/空）；
- **行 3-6 为合成行**（编码行 / 同名空编码重复行 / 名称空行 / 归属A IP 坏值行），**第二表「基站表-含地市」整表为合成**（地市列 + 合成行），用于演示兜底键的地市作用域语义；
- 生成脚本保存在仓库外 `/home/z/my-project/scripts/gen_base_station_sample.py`（确定性、无随机），重生成产物与入库文件字节一致；
- **W004 行为说明**：空编码行走条件自然键——键退化为 `地市|无线基站名称` 兜底（本样例首表无地市列，退化为纯名称），行照常导入并记 W004 治理 issue（warning）；预期导入结果 4 imported / 4 failed（2×E001 + E002 + E004）、3×W004；重导幂等（0 新增）。
